# 🤖 omni-rag-saas

> **Multi-Tenant No-Code AI Chatbot & Automation SaaS Platform**

omni-rag-saas is a futuristic B2B cloud platform enabling businesses and individual tenants to build high-performance AI chatbots using their custom data (PDF, Docs, Web Links) in under 1 minute — without writing any code.

---

## 🌟 Key Features
- **Multi-Tenant Isolation**: Complete database and vector-store isolation for strict security and data privacy.
- **Advanced RAG Engine**: Intelligent chunking, context retrieval, and vector search powered by Google Gemini and Vector DBs.
- **Fail-Safe Pipeline**: Auto-routing mechanism to secondary AI models ensuring 99.9% uptime.
- **No-Code Dashboard**: Slick dark-themed UI to manage bots, data sources, and integrations easily.
