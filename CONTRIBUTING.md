# Contributing to omni-rag-saas 🚀

We welcome contributions from developers, designers, and AI enthusiasts worldwide!

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
Commit Your Changes:

Bash
git commit -m "feat: add amazing feature"
Push to the Branch:

Bash
git push origin feature/amazing-feature
Open a Pull Request (PR)

Code Standards
Keep backend API modular and strictly typed where possible.

Ensure all multi-tenant logic enforces tenant ID isolation.

Add clear comments for complex RAG routing logic.

Thank you for helping us build the future of AI chatbots!
